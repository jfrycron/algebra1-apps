# Fact Families
Three activities: place numbers into four related facts, type the facts, and complete a missing-number triangle. Factors range from 1 to 12. A facts selector supports focused practice.

Schoology link: https://jfrycron.github.io/algebra1-apps/fact-families/

Editable React source is in `source/`. To rebuild, run `npm install` then `npm run build` there. The build writes the static site into this folder.
